# 🤝 Contributing to Resolution Club Website

Thank you for contributing to the Resolution Club Website 🚀

This project is collaboratively developed to create a professional digital platform for the Resolution media club.

---

# 🌱 Getting Started

## Workflow

1. Fork the repository
2. Clone your fork
3. Create your personal branch
4. Make changes
5. Commit changes
6. Push your branch
7. Open a Pull Request

---

# 📥 Clone Repository

```bash
git clone https://github.com/your-username/resolution-club-website.git
cd resolution-club-website
```

---

# 🌿 Branch Naming Convention

Each member should work in their own branch.

## Format

```bash
yourname/section-name
```


# 🔀 Create Your Branch

```bash
git checkout -b yourname/section-name
```

---

# ✅ Contribution Guidelines

Please ensure:

- Clean and readable code
- Responsive design maintained
- Reusable components
- Proper file naming
- No unnecessary dependencies
- Optimized media usage

---

# 🧾 Commit Message Format

```bash
type(scope): short description
```

---

# 📌 Commit Types

| Type       |    Description |
|-------------|-------------|
|feat         | New feature |
|fix           | Bug fix |
|docs       | Documentation |
|style       | UI/Styling updates |
|refactor  | Code improvement |
|test        | Testing updates |
|chore     | Miscellaneous work |

---


# ✅ Commit Example
```bash
feat(home): add hero section animation


# 🚫 What NOT to Do

- ❌ Do NOT push directly to `main`
- ❌ Do NOT upload unnecessary large files
- ❌ Do NOT commit secrets or API keys
- ❌ Do NOT mix multiple unrelated changes

---

# 🔍 Pull Request Guidelines

Before opening a PR:

- Test your changes
- Ensure responsiveness
- Check for console errors
- Add screenshots for UI changes
- Write proper PR descriptions

---

# 📱 Responsiveness Checklist

Test your work on:

- Mobile (<768px)
- Tablet (768px–1280px)
- Desktop (>1280px)

---

# 🔐 Security Practices

- Validate inputs
- Sanitize forms
- Protect admin routes
- Use secure environment variables
- Avoid exposing credentials

---

# 👨‍💻 Code Review Process

- All PRs will be reviewed before merging
- Feedback may be requested
- Approved changes will be merged into the main branch

---

# 🔄 Syncing Your Fork

```bash
git remote add upstream https://github.com/ExploitX-org/Resolution-Webpage.git
git pull upstream main
```
